##  Project Overview

This project was given as part of the Digital Literacy course. The aim of this project is to understand how to use digital tools effectively and responsibly. Through this project, I learned about creating online profiles, safe internet practices, professional communication, and awareness about cybercrime.

I have completed five different tasks, each based on a module of the course. All the work is organized in this repository with proper folders and files.

---

##  Task 1: Digital Literacy Infographic

In this task, I created an infographic using Canva. The infographic explains what digital literacy is, some useful tools for students, safe internet practices, and basic email etiquette. I tried to keep the design simple and easy to understand by using short points and icons.

---

##  Task 2: Digital Portfolio

For this task, I created my profiles on GitHub, LinkedIn, and Kaggle.  
- GitHub is used to store and manage my projects.  
- LinkedIn helps in building a professional profile.  
- Kaggle is useful for learning and practicing skills.  

I also created a GitHub profile README and added my education details on LinkedIn.

---

##  Task 3: Coding & Collaboration Platforms

In this task, I explored a coding platform and a collaboration tool.  
I used HackerRank and solved a beginner-level problem to understand how coding platforms work.  

I also created a Google Form titled "Digital Literacy Awareness Quiz" with five questions. This helped me learn how to create quizzes and collect responses using Google Sheets.

##  Task 4: Email Etiquette & Social Media Guidelines

In this task, I wrote two professional emails:  
- One for requesting assignment extension  
- One for internship inquiry  

I also created a checklist of Do’s and Don’ts for social media use. This helped me understand how to communicate properly online and maintain professionalism.

---

##  Task 5: Cybercrime Awareness

For this task, I worked on a case study based on UPI fraud. I explained how such frauds happen, who gets targeted, and their consequences.  

I also created a prevention checklist with important safety tips. This task made me more aware of online risks and how to stay safe.

---

##  Conclusion

Overall, this project helped me understand the importance of digital literacy in daily life. I learned how to use different platforms, communicate professionally, and stay safe online. These skills will be very useful for me in my academic journey and future career.
